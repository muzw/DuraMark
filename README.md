# DuraMark

**DuraMark** is a duration-based audio watermarking framework for speech synthesis. It embeds invisible watermarks into synthesized speech by subtly adjusting phoneme-level durations during TTS generation, and detects them using a dedicated duration detector model — remaining robust against various audio perturbations (noise, compression, re-recording, etc.).

## How It Works

1. **Embedding**: During TTS synthesis (CosyVoice), watermark bits are encoded by modulating character-level durations — even frame counts represent bit `0`, odd frame counts represent bit `1`.
2. **Detection**: A DurationDetector model recovers per-character durations from the audio. A soft-voting / DP-alignment algorithm then decodes the watermark bits, even when the audio has been distorted.

## Environment Setup (Conda)

### 1. Create a conda environment

```bash
# Create a new environment with Python 3.10
conda create -n duramark python=3.10 -y

# Activate the environment
conda activate duramark
```

### 2. Install PyTorch (CUDA 12.1)

Choose the appropriate PyTorch version for your CUDA driver. The example below is for CUDA 12.1:

```bash
# CUDA 12.1
pip install torch==2.3.1 torchaudio==2.3.1 --index-url https://download.pytorch.org/whl/cu121

# If you have CUDA 11.8, use:
# pip install torch==2.3.1 torchaudio==2.3.1 --index-url https://download.pytorch.org/whl/cu118

# Verify PyTorch can see your GPU
python -c "import torch; print(f'CUDA available: {torch.cuda.is_available()}'); print(f'GPU: {torch.cuda.get_device_name(0)}')"
```

### 3. Install DuraMark and dependencies

```bash
# Clone the repository (with Matcha-TTS submodule)
git clone --recursive https://github.com/DuraMark/DuraMark.git
cd DuraMark

# Install DuraMark in editable mode
pip install -e .

# Verify the installation
python -c "import duramark; print(f'DuraMark version: {duramark.__version__}')"
```

### 4. Prepare model weights

The pre-trained model weights are not included in the repository. Copy them from your training output directory or use the download script:

```bash
# Option A: Use the download script (when URLs are configured)
duramark download-models --output_dir ./models --models all

# Option B: Manually copy from your training directory
# You need two model sets:
#
# 1. TTS model (for watermark embedding):
#    ./models/tts/
#    ├── llm.pt
#    ├── flow.pt
#    ├── hift.pt
#    ├── cosyvoice.yaml
#    ├── campplus.onnx
#    └── speech_tokenizer_v1.onnx
#
# 2. Detector model (for watermark detection):
#    ./models/duration_detector/
#    ├── duration_detector.pt
#    └── duration_detector.yaml
```

### 5. Verify model loading


## Input File Format

### text.scp — Text to synthesize

Each line contains a **utterance ID** and the **text content** to be synthesized (with watermark):

```
utt_id1 温和到爆炸一点都不刺激
utt_id2 今天天气真不错适合出去散步
utt_id3 人工智能正在改变我们的生活方式
```

### ref_text.scp — Reference text

Each line contains the utterance ID and the **ground-truth text** of the reference audio:

```
utt_id1 参考音频对应的原始文本内容
utt_id2 这是参考音频的原始文本
utt_id3 参考文本需要与参考音频精确对应
```

### ref_wav.scp — Reference audio path

Each line contains the utterance ID and the **path** to the reference audio (WAV, 16kHz mono preferred):

```
utt_id1 /path/to/reference/utt_id1.wav
utt_id2 /path/to/reference/utt_id2.wav
utt_id3 /path/to/reference/utt_id3.wav
```

### Additional data: word-level intervals

For each reference audio, a corresponding `.npy` file containing character-level time intervals is required. The interval file path is automatically derived from the audio path:

```
# If ref_wav.scp has:
#   utt_id1 /data/audio/utt_id1.wav
# Then the interval file should be at:
#   /data/interval/utt_id1.npy
#
# (i.e., replace "audio" with "interval" and ".wav" with ".npy" in the path)
```

The `.npy` file is a numpy array of shape `(N, 2)`, where each row is `[start_time, end_time]` in seconds for one character. For example, a 8-character text produces shape `(8, 2)`:

```python
import numpy as np
arr = np.load("interval/utt_id1.npy")
# Example: array([[0.46, 0.76], [0.76, 1.02], [1.02, 1.36], ...])
```

These interval files are generated by **forced alignment** between the reference audio and its text transcription. Common tools:

- **MFA (Montreal Forced Aligner)** — requires Chinese acoustic model + G2P (grapheme-to-phoneme)
- **WeNet toolchain** (included in the original CosyVoice repo under `examples/wenet/cosyvoice/tools/extract_interval.py`)
- Any forced alignment tool that outputs per-character `[start, end]` timestamps in seconds

## Quick Start

After completing the environment setup above:

### 1. Embed a watermark into speech

```bash
duramark embed \
    --model_dir ./models/tts \
    --input text.scp \
    --ref_text ref_text.scp \
    --ref_wav ref_wav.scp \
    --output_dir ./output \
    --watermark_length 8 \
    --device cuda:0
```

Output files will be named like `utt_id1_10101100.wav` where the suffix is the embedded watermark.

### 2. Detect the watermark (text mode)

Use when you have the **ground-truth text** of the synthesized speech:

```bash
duramark detect \
    --model_dir ./models/duration_detector \
    --input_dir ./output \
    --text_scp text.scp \
    --watermark_length 8 \
    --mode text \
    --device cuda:0
```

### 3. Detect the watermark (ASR-blind mode)

Use when you only have **ASR transcription** of the speech (not ground-truth text). Requires a `transcription_results.txt` file in the input directory:

```bash
duramark detect \
    --model_dir ./models/duration_detector \
    --input_dir ./output \
    --text_scp text.scp \
    --watermark_length 8 \
    --mode asr \
    --device cuda:0
```

## CLI Reference

```
duramark embed       # Embed watermark during TTS synthesis
duramark detect      # Detect watermark from audio files
duramark download-models  # Download pre-trained models
```

### embed options

| Option | Required | Default | Description |
|--------|----------|---------|-------------|
| `--model_dir` | yes | — | Path to TTS model directory |
| `--input` | yes | — | Input text SCP file (utt_id text) |
| `--ref_text` | yes | — | Reference text SCP file |
| `--ref_wav` | yes | — | Reference audio SCP file |
| `--output_dir` | yes | — | Output directory for generated WAVs |
| `--watermark_length` | no | `8` | Number of watermark bits |
| `--device` | no | `cuda:0` | Inference device |
| `--num_gpus` | no | `1` | Number of GPUs for parallel processing |
| `--workers_per_gpu` | no | `1` | Worker processes per GPU |

### detect options

| Option | Required | Default | Description |
|--------|----------|---------|-------------|
| `--model_dir` | yes | — | Path to detector model directory |
| `--input_dir` | yes | — | Directory containing WAV files to evaluate |
| `--text_scp` | yes | — | Text SCP file (utt_id text) |
| `--watermark_length` | no | `8` | Number of watermark bits |
| `--mode` | no | `text` | Detection mode: `text` or `asr` |
| `--device` | no | `cuda:0` | Inference device |
| `--output` | no | — | Path to save per-file results CSV |
